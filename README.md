# Financial Manager

A modern financial management application built with React and TypeScript that helps you track and manage your transactions.

## Features

- View all financial transactions in a clean, organized table
- Add new transactions with category, description, value, and date
- View detailed transaction information in a modal
- Dark mode support for comfortable viewing in any environment

## Tech Stack

- React
- TypeScript
- Vite
- CSS3 with custom properties (variables)

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```
